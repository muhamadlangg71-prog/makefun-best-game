Lanternfall — Keeper of the Last Light: a wave-based arena survival shooter. The dark has swallowed the world and one lantern still burns; you are its keeper. Hold the light through 10 waves of shadow creatures, pick upgrades between waves, and don't let the lantern — or yourself — fall. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```
